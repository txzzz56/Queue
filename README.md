# Queue demonstration

Et Java-prosjekt som demonstrerer hvordan en Queue (kø) fungerer ved hjelp av JavaFX.
Funksjoner
+ Legge til elementer
- Fjerne elementer
 Vise køen
 Sortere elementene
📊Vise kø-status
Sirkulær kø med array


# Teknologier
Java
JavaFX
Arrays

# Prosjektstruktur
Queue/
├── Queue.java
└── QueueDemo.java

Queue.java inneholder selve kø-logikken, mens QueueDemo.java inneholder JavaFX-grensesnittet.


# Hvordan kjøre
Åpne prosjektet i IntelliJ IDEA.
Sørg for at JavaFX er konfigurert.
Kjør QueueDemo.java.
Skriv inn ønsket størrelse på køen og bruk knappene.
